## 3. 环境与复现

依赖：Python 3、gcc、Verilator 5.034、NEMU（`a683e0b` + 补丁）、JDK/mill/firtool（Chisel 生成）、香山源码与 emu、Yosys 0.52（generic 综合）。工具部署在本地 `.tools/`（不随仓库分发）。

```bash
# 单元回归（3047/3047，三模式）
bash scripts/run_unit_tests.sh

# Chisel 生成 RTL + 等价回归（3047/3047）
bash scripts/run_chisel_equiv.sh

# 全链路：unit / lint / chisel / nemu / rtl_export / cosim / baseline
bash scripts/run_all.sh     # 末行打印 ALL : PASS

# generic 综合（三模式 7427 单元 / 356 FF / 25 级）
export PATH="$PWD/.tools/yosys/usr/bin:$PATH" YOSYS_DATDIR="$PWD/.tools/yosys/usr/share/yosys"
yosys -p "read_verilog -sv rtl/verilog/VDot.v; synth -top VDot -noabc; techmap; opt; splitnets -ports; opt; ltp -noff; stat"

# 重新生成操作截图与录屏
python3 scripts/make_operation_recordings.py

# 阶段一解说字幕版（ffmpeg + edge-tts）
python3 scripts/make_stage1_narration.py
```

预期关键输出：`cases_pass 3047`、`cases_fail 0`、`latency_write 3 cycle`、`throughput 1 inst/cycle`、`mac_per_cycle int8=8 int4x2=16 vtdot=16`、`rtl_vs_nemu ... mismatch=0`、`ALL : PASS`、综合 `7427` 单元与 `length=25`。

## 4. 结论摘要

- 单元回归 **3047/3047**（三模式），行覆盖率 **55/55**，Chisel 与 Verilog 同向量等价。
- NEMU↔金标准↔RTL **3032 用例 / 4551 结果字，0 mismatch**；边界自检覆盖三模式 `vl=0` 不写回与 4 类非法配置。
- 纯 RVV 组合基线 **1513/1513**（INT8），数据通路指令 **6→1**。
- BitNet b1.58 融合：三值权重 2-bit 编码、16 MAC/指令、零乘法器、权重相对 INT8 **4× 压缩**，与 INT4 共享两棵 12-bit 归约树。
- 香山 emu（NITER=2000，3 次重复极差 0，INT8）：**0.5075 cycle/点积**，对标量 **9.8×**（8-lane 公平），对 RVV 基线 **11.8×**（16-lane，属上界）。
- 严格 lint 0 告警；generic 综合 **三模式 7427 单元 / 356 FF / 最长 R2R 25 级**（≈10.1k–15.8k GE），INT8 单模式对照 **4187 单元 / 172 FF / 25 级**（≈5.35k–8.38k GE）。

## 5. 表述边界

- 不宣称 PDK 级面积/时序、真实频率下的绝对性能、FPGA 或流片结果。
- 11.8× 为对 16-lane RVV 基线的上界；lane 公平主结论为 9.8×。
- generic 综合为工艺无关结果（Yosys `synth -noabc`），只有单元数与拓扑深度，不含 µm² 与 ns；`7427 / 356 / 25` 为三模式实测，`4187 / 172 / 25` 为同流程对 INT8 单模式 RTL 的复核。
- 系统级 emu 实测仅覆盖 INT8；INT4/三值已完成单元 + NEMU + Chisel 闭环，emu 重跑列为后续项。
