## 3. 关键结论（供填报项目简介）

- **功能**：`vdot.vv`（INT8）、`vdot4x2.vv`（INT4 打包、双结果）、`vtdot.vv`（BitNet b1.58 三值、双结果、零乘法器）；三条指令统一 SEW=8 / LMUL=1 / vm=1，单 uop 完成一组乘累加。
- **验证**：单元回归 3047/3047（三模式）、行覆盖率 55/55；NEMU↔金标准↔RTL 3032 用例 / 4551 结果字，0 mismatch；香山 emu 定向 7/7、非法 5/5（INT8）。
- **性能**：单元级 3 cycle / 1.0 inst·cycle⁻¹，MAC/cycle = 8:16:16（INT8/INT4/三值）；香山 emu 实测 0.5075 cycle/点积，对标量 9.8×（8-lane 公平）、对 RVV 基线 11.8×（16-lane，属上界），NITER=2000，3 次重复极差 0（INT8）。
- **BitNet 融合**：三值权重 2-bit 编码（16 权重 = 32 bit，相对 INT8 4× 压缩），EX1 仅选择/取反/清零，无乘法器；缩放 β·γ 在指令外折叠；与 INT4 共享 EX2 两棵 12-bit 归约树。
- **基线**：香山 `16ae9dd`（2025-04-03，昆明湖 V2 基线快照：V2/V3 共同祖先提交，DefaultConfig（VLEN=128）构建，未启用 V3 配置）。
- **实现**：Verilog 与 Chisel 双版本等价；严格 lint 0 告警；generic 综合 **三模式 7427 单元 / 356 FF / 最长路径 25 级（≈10.1k–15.8k GE）**，INT8 单模式对照 4187 单元 / 172 FF / 25 级（≈5.35k–8.38k GE）；关键路径深度与终点不变。
